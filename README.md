# Telão para Windows

Instaladores do **Telão**: salas com chat, call e transmissão de tela, com áudio por aplicativo.

## Baixar

Abra a [última versão](https://github.com/EmanuelSLisandro/telao-releases/releases/latest) e baixe o arquivo
`Telao-Setup-<versão>.exe`.

O app se atualiza sozinho depois de instalado.

**O app não é assinado.** Na primeira instalação o Windows SmartScreen mostra "O Windows protegeu o computador".
Clique em **Mais informações → Executar assim mesmo**.
